개인정보처리방침

시행일 2026년 9월 14일

갈무리부엌(이하 “서비스”)은 개인 개발자가 운영하는 냉장고 재고·레시피·장보기 웹앱이에요. 서비스에 꼭 필요한 만큼만 정보를 받고, 어디에 쓰고 누구에게 맡기는지 아래에 적어 둘게요.

1. 받는 정보

  • 로그인할 때 — 카카오·네이버·구글이 알려 주는 회원 번호와 닉네임(이름). 이메일, 전화번호, 프로필 사진은 받지 않아요.
  • 직접 넣은 내용 — 재고, 레시피, 양념 비율, 장보기 목록과 메모, 메모에 올린 사진, 재료를 뺀 이유, 요리 채널 목록.
  • AI 기능을 쓸 때 — 사진으로 재료 추가에 올린 사진과 AI 레시피에 쓸 재료 목록. 결과를 받는 데만 쓰고 사진은 저장하지 않아요.
  • 자동으로 남는 것 — AI·외부 기능 사용 기록(기능 종류, 사용량, 시각), 서버 접속 기록(IP 주소, 요청 주소, 시각), 로그인을 유지하는 쿠키.
  • 체험 계정 — 같은 곳에서 계정을 너무 많이 만들지 못하게, IP 주소를 그대로 두지 않고 되돌릴 수 없는 값의 일부만 남겨요.

2. 쓰는 곳

  • 로그인과 내 데이터 보여 주기
  • 사진 속 재료 찾기, AI 레시피 만들기, 레시피·영상 추천
  • 하루 사용 한도 지키기와 비용 계산, 남용 막기, 오류 확인

광고나 마케팅에 쓰지 않고, 다른 곳에 팔거나 넘기지 않아요.

3. 맡기는 곳 (처리 위탁·국외 이전)

서비스를 돌리기 위해 아래 회사에 정보 처리를 맡겨요. 모두 인터넷으로 암호화해서 보내요.

회사 (국가)맡기는 일보내는 정보보관
Render Services, Inc. (서버 위치 싱가포르)서버·데이터베이스 운영1번의 모든 정보계정을 지울 때까지
Cloudflare, Inc. (미국, R2 저장소)장보기 메모 사진 보관메모에 올린 사진사진이나 계정을 지울 때까지

영상 목록은 YouTube API 서비스에서, 추천 레시피는 식품의약품안전처 공공 데이터에서 받아 와요. 이때 이용자 정보는 보내지 않아요. 영상 기능에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용돼요.

4. 보관 기간과 삭제

  • 체험 계정 — 만든 지 24시간이 지나면 계정과 모든 데이터, 사진을 지워요.
  • 로그인 계정 — 삭제를 요청하면 계정과 모든 데이터, 사진을 지체 없이 지워요.
  • AI 사용 기록 — 계정을 지우면 누구의 기록인지 알 수 없게 끊고, 사용량 숫자만 비용 계산에 남겨요.
  • 서버 접속 기록 — 호스팅 회사(Render)의 로그 보관 기간 동안만 남아요.

5. 이 기기에 저장하는 것

인터넷이 끊겨도 장보기 목록을 보고 고칠 수 있게, 목록과 보내지 못한 변경을 브라우저 저장소에 둬요. 화면 테마 같은 설정도 브라우저에 저장해요. 로그아웃하면 장보기 데이터는 이 기기에서 지워요.

6. 이용자가 할 수 있는 것

  • 내려받기 — 더보기 → 데이터 내보내기에서 내 데이터를 파일로 받아요.
  • 고치기·지우기 — 앱에서 직접 고치거나 지울 수 있고, 계정 전체 삭제는 아래 문의처로 요청해요.
  • 연결 끊기 — 카카오·네이버·구글 계정 설정에서 갈무리부엌 연결을 끊을 수 있어요.

7. 만 14세 미만

만 14세 미만 아동을 대상으로 한 서비스가 아니에요.

8. 안전하게 지키는 방법

  • 모든 연결은 HTTPS로 암호화해요.
  • 메모 사진은 공개되지 않은 저장소에 두고, 올린 본인만 볼 수 있어요.
  • API 키 같은 비밀 값은 코드에 넣지 않고 서버 설정에만 둬요.
