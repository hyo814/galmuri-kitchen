재고 사진 여러 장 · 구입일 칩 · ‘기억 안 나요’

사진으로 추가할 때 한 번에 최대 5장을 모아 AI가 한 번에 읽고(오늘 남은 횟수는 1번만 줄어요), 겹친 재료는 하나로 합쳐요. 확인 화면의 구입일은 칩으로 빠르게 고르고, 모르면 기억 안 나요로 비워 둘 수 있어요. 재료마다 따로 고치는 것도 돼요.

화면 흐름: ① 종류 고르고 찍기(지금과 같음) → ② 사진 모으기 → ③ 찾는 중 → ④ 확인(구입일 칩) → ⑤ 한 재료만 다른 날 → ⑥ 재고 목록.

A. 첫 사진 뒤 바로 읽을까, 모아서 읽을까

시안은 모아서 읽기예요. 한 장만 찍어도 ‘1장 읽기’ 한 번만 누르면 돼요.

B. ‘기억 안 나요’면 오래됨 경고는?

시안은 경고 없음. 유통기한을 넣은 재료만 임박·지남을 알려줘요. 목록에는 날짜 대신 아무것도 안 보여요.

C. 냉장고 사진의 첫 선택

시안은 냉장고 사진이면 아무 칩도 안 고른 상태로 시작해 고르게 해요(영수증·주문은 찍힌 날짜가 먼저 골라져요).
