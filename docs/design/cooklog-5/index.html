5단계 요리 일기 · 집밥 리포트

레시피나 식단 칸에서 요리했어요 → 쓴 재료를 재고에서 빼고, 사진·별점·메모와 아낀 돈(사 먹으면 얼마 − 재료비)을 남겨요. 더보기 > 기록에 요리 일기, 한 달 모아 집밥 리포트. 먹은 기록 달력에는 요리한 날 `요` 표시가 붙어요(24절).

화면: ① 요리했어요 폼 → ② 저장 후 → ③ 요리 일기 목록 → ④ 일기 상세(아낀 돈 계산) → ⑤ 집밥 리포트 → ⑥ 재료 지울 때 이유.

A. 사 먹으면 얼마

시안: ① 내가 쓴 값 → ② AI 추정(레시피에 저장, 한 번만). 참가격 외식비는 8품목뿐이라 API 조건이 확인되면 붙여요. 폼에서 값을 바로 고칠 수 있어요.

B. 일기 지우면 재고는?

시안: 저장 직후 10초 되돌리기(재고 복구). 그 뒤 일기를 지우면 기록만 지우고 재고는 그대로라고 안내해요.

C. 식단 칸과 연결

시안: 식단 칸 먹었어요 옆에 요리했어요 — 그 칸 요리·인분으로 폼을 열고, 저장하면 먹은 기록도 함께 남아요.

D. 버린 재료 세기

시안: 재고에서 지울 때 다 먹었어요 · 버렸어요 · 그냥 지우기(기본). 리포트는 ‘버렸어요’만 세요.
