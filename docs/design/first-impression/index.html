추천: 4초마다 자동. 점을 누르면 멈춰요. 기기에서 움직임 줄이기를 켠 분에게는 넘기지 않아요.

③ 체험 안내는 몇 번 보여 줄까?

추천: 체험 계정마다 한 번. 닫거나 버튼을 누르면 다시 뜨지 않아요. 가리는 덮개 대신 화면 안의 카드라 바로 무시해도 돼요.
