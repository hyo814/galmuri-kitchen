예시 사진으로 체험하기 시안

투표하러 온 사람은 냉장고 앞에 있지 않아요. 그래서 체험 계정에만 직접 찍은 예시 사진 3장을 두고, 고르면 진짜 AI가 그 자리에서 읽어요. 저장해 둔 결과를 바로 띄우지 않아요.

가짜처럼 보이지 않게 하는 장치: ① 결과 화면에서 사진과 찾은 재료를 같이 보여 줘요 ② 읽는 데 걸린 시간을 적어요 ③ 예산이 떨어져 저장된 결과를 쓸 때는 그렇다고 밝혀요.

화면 흐름: ① 체험 첫 안내 → ② 사진으로 추가(예시 사진) → ③ 사진 확인 → ④ 읽는 중 → ⑤ 확인(사진 비교) → ⑥ 예산이 떨어졌을 때. 사진 자리는 그림이고, 실제로는 직접 찍어 주신 사진을 가려서 써요.

A. 사진과 결과를 어떻게 비교할까

⑤-A 위에 사진 띠를 추천해요. 스크롤하면서 영수증 줄과 재료를 바로 맞춰 봐요. ⑤-B는 작은 사진을 눌러 크게 보는 방식이에요.

B. 예시 사진 몇 장

3장 · 영수증 · 냉장고 · 주문 캡처. 지금 사진 종류 3개와 같아서 고른 사진이 종류도 정해요.

C. 체험 첫 안내 카드

체험 계정 재고 화면 맨 위, 닫으면 다시 안 보임. 로그인 사용자에게는 안 보여요.

D. PC에서 보면

‘카메라로 찍기’는 PC에 카메라가 없어 헷갈려요. PC에서는 ‘사진 파일 올리기’ 버튼 하나로 바꿔요(화면은 같음).
