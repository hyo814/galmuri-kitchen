# 갈무리부엌 시연 시나리오

라이브 데모 3분과 소개 영상 1분의 흐름입니다. 모든 단계는 배포 주소의 체험 계정 기준입니다(배포 후).
화면 파일 이름은 `docs/submission/screenshots/`의 스크린샷과 같습니다.

## 준비물

| 항목 | 내용 |
|---|---|
| 기기 | 갤럭시 S22 Ultra, 크롬. 홈 화면에 설치한 앱으로 엽니다. |
| 화면 공유 | USB 미러링. 비행기 모드를 켜도 끊기지 않아야 합니다(와이파이 미러링은 쓰지 않습니다). |
| 사진 | 마트 영수증 1장(식재료 4~6개, 봉투 포함, 된장·청양고추·마늘은 빼기), 손으로 쓴 장보기 메모 1장("우유, 계란, 수세미, 참기름"). 폰 앨범에 미리 넣어 둡니다. |
| 서버 깨우기 | Render 무료 플랜은 잠들어 있으면 첫 접속이 30초가량 걸립니다. 시작 5분 전에 한 번 엽니다. |
| 체험 계정 | 시작 직전에 새로 만듭니다. 같은 IP에서 1시간에 3개까지라 리허설 횟수를 셉니다. |
| AI 횟수 | 체험 계정은 사진 인식·AI 레시피가 하루 3번씩입니다. 이 시나리오는 각각 2번 씁니다. |

### 막혔을 때

| 상황 | 대응 |
|---|---|
| 첫 접속이 느림 | "무료 서버가 깨어나는 중입니다"라고 말하고 기다립니다. 5분 전 깨우기를 잊지 않습니다. |
| 사진 인식 실패 | 오류 화면에서 직접 입력으로 넘어갑니다. "AI가 못 읽으면 직접 입력으로 이어집니다"라고 말합니다. |
| 체험하기가 막힘(`너무 많이 눌렀어요`) | 리허설에서 만든 체험 계정으로 들어갑니다. 리허설 계정 하나는 남겨 둡니다. |
| AI 레시피가 예시 결과로 나옴 | 체험 계정 전체 예산을 넘은 경우입니다. "비용 한도에 걸리면 예시 결과로 바뀝니다"라고 설명합니다. |
| 오프라인에서 앱이 안 열림 | 서비스 워커 설치와 목록 저장은 온라인으로 한 번 열어야 됩니다. 시연 전에 온라인으로 장보기 탭을 한 번 엽니다. |
