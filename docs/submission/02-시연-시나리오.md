## 준비물

| 항목 | 내용 |
|---|---|
| 기기 | 갤럭시 S22 Ultra, 크롬. 홈 화면에 설치한 앱으로 엽니다. |
| 화면 공유 | USB 미러링. 비행기 모드를 켜도 끊기지 않아야 합니다(와이파이 미러링은 쓰지 않습니다). |
| 사진 | 마트 영수증 1장(식재료 4~6개, 봉투 포함, 된장·청양고추·마늘은 빼기), 냉장고 안 사진 1장(여러 장 인식 질문용), 손으로 쓴 장보기 메모 1장("우유, 계란, 수세미, 참기름"). 폰 앨범에 미리 넣어 둡니다. |
| 서버 확인 | 유료 상시 인스턴스라 잠들지 않습니다. 시작 5분 전에 한 번 열어 뜨는지만 봅니다. 시연 직전에는 push하지 않습니다(배포 중 몇 분간 이전 버전·재시작이 섞일 수 있음). |
| 체험 계정 | 시작 직전에 새로 만듭니다. 같은 IP에서 1시간에 30개까지라 리허설로 막힐 일은 거의 없습니다. |
| AI 횟수 | 체험 계정은 사진 인식 하루 5번, AI 레시피 하루 5번입니다. AI 레시피 5번은 AI 레시피·링크/사진 가져오기·AI 식단 초안이 함께 씁니다. 3분 데모는 사진 인식 1번·AI 레시피 1번을 쓰고, 질문 대응까지 하면 AI 레시피 쪽이 먼저 찹니다. 더 필요하면 체험하기를 새로 누릅니다. |
