# 제출 양식 답안

원티드 AI Championship 2026 제출 양식에 그대로 붙여 넣을 답안입니다.
코드 블록 안의 글이 붙여 넣을 내용입니다. 답안은 심사위원이 읽는 글이라 합니다체로 맞췄습니다.
수치는 2026-09-17 최종 제출 기준(`main` `3376c45`)입니다.

## 1. 제목 (30자 이내)

추천:

```text
갈무리부엌 — 사둔 재료, 남김없이 챙겨요
```

다른 안:

```text
갈무리부엌: 재고로 요리하고, 모자란 것만 장보기
```

```text
갈무리부엌 — 재고·레시피·장보기·식단을 한 흐름으로
```

## 2. 해결하고자 한 문제 (한 줄, 60자 이내)

추천:

```text
사둔 재료를 잊어 상하게 두고, 집에 있는 재료를 모른 채 또 사는 문제
```

다른 안:

```text
재고 기록은 번거로워 멈추고, 레시피와 장보기는 내 냉장고를 모르는 문제
```

```text
남은 재료로 뭘 만들지 몰라 새로 사고, 사둔 재료는 버려지는 문제
```

## 3. AI 활용 방식 및 결과

### 본문 (권장)

```text
■ 서비스 안의 AI — Claude API(Anthropic)
- 사진 인식: 영수증·냉장고 사진·주문 캡처(최대 5장을 한 번에)와 손메모를 Claude(claude-sonnet-5)가 읽어 재료·수량·보관 위치·금액·구입일을 채웁니다. 사용자는 확인 화면에서 틀린 곳만 고쳐 넣습니다.
- AI 레시피: 곧 먹어야 할 재료를 표시한 재고를 넘겨, 그 재료를 먼저 쓰는 레시피 3개를 받습니다.
- 레시피 가져오기: 유튜브 설명란·블로그 글(본문 사진 포함)·붙여 넣은 글·요리책 사진을 레시피 초안으로 정리합니다.
- AI 식단 초안: 끼니·목표 kcal·메모를 받아 빈 칸마다 후보 2개와 1인분 kcal 추정을 만들고, 사용자가 체크한 칸만 넣습니다. 식단에서 모자란 재료는 장보기 목록으로 만듭니다.
- 영양 추정: 레시피 재료를 식품영양성분 DB(공공데이터포털)에서 먼저 찾고, 찾지 못한 재료의 100g당 영양과 한 단위 무게(두부 1모 등)만 Claude가 추정해 '추정'으로 표시합니다.
- 사 먹으면 얼마 추정: 레시피 이름과 재료 이름으로 1인분 외식 가격을 한 번 추정해 레시피에 저장합니다. 요리 일기의 아낀 돈 계산에 씁니다.
- 모든 호출은 구조화 출력(messages.parse + Pydantic 스키마)으로 형식을 강제하고, 형식이 틀리면 결과를 쓰지 않습니다.

■ 안전장치
- 사용자별 하루 한도(사진 20번, 레시피·가져오기·식단 초안·사 먹으면 얼마 합쳐 20번, 영양 추정 따로 20번)와 60초 연속 제한
- 체험 계정 전체 24시간 80번 예산(배포 설정), 넘으면 예시 결과. 영양 추정은 체험 계정당 2번·체험 전체 하루 30번
- 서버가 결과를 다시 정리(개수·길이·수량·금액 범위)
- 메모 사진·가져온 글 속 문장은 지시가 아닌 자료로만 보는 프롬프트 규칙
- 링크 가져오기 SSRF 방어: 공인 IP만 연결, 리다이렉트마다 재검사, 전체 8초 제한

■ 만드는 과정의 AI — Claude Code
- 설계 문서 → 화면 시안 → 태스크별 계획 → 기능마다 git worktree에서 구현했습니다.
- 리드 에이전트가 계획을 쓰고, 태스크마다 구현 에이전트, 병렬 검토 에이전트(코드·보안·UX·접근성·테스트 설계), 검증 에이전트, 단계 끝 최종 검토와 화면 흐름 점검이 붙었습니다.
- 사람은 기능 범위와 기준을 정하고 시안을 승인했습니다.
- 검토에서 잡은 예
  ① 응답을 조금씩 보내는 서버가 시간 제한을 넘김 → 감시 타이머로 연결 종료
  ② 세션 만료 시 오프라인 체크가 사라짐 → 대기열 보존
  ③ 채널 추가 반복으로 YouTube API 한도 소진 → 사용자별·전체 예산
  ④ 쿠팡 단축 링크 허용 검사 우회(오픈 리다이렉트) → 주소 전체를 정규식으로만 허용
  ⑤ 빈 메모 자동 정리와 메모 저장이 다른 잠금을 잡아 글이 지워질 수 있음 → 같은 잠금 순서로 통일

■ 수익 구조와 원가
- 쓸수록 드는 비용은 대부분 AI 호출입니다. 호출마다 모델과 토큰을 기록하고 있고, 추정 원가는 영수증 1장 인식 약 13원, AI 레시피 3개 약 30원, 한 주 식단 초안 약 70원입니다.
- 재고·임박 경고·공공 레시피 추천·오프라인 장보기처럼 AI가 필요 없는 기능은 무료로 둡니다. 유료 구독(월 2,900~4,900원 검토)은 비용이 드는 AI 사용 횟수로만 무료와 나누고, 원가가 없는 레시피 개수에는 제한을 두지 않습니다.
- 구독할 이유는 집밥 리포트의 '아낀 돈'(사 먹으면 얼마 × 인분 − 쓴 재료비, 추정값)으로 보여 드립니다. 집밥 리포트에서 볼 수 있습니다.
- 장보기의 쇼핑몰 링크는 쿠팡 파트너스 제휴 링크로 바꿀 수 있게 만들어 두었고, '광고' 표시를 붙이며 쇼핑몰 순서는 수수료와 상관없습니다. 키 발급은 실적 조건 때문에 심사·투표 기간 안에는 어려워 이번 제출에서는 키를 넣지 않았고, 지금은 모두 일반 검색 링크입니다.
- 서버와 DB는 월 약 2만 원(추정)이라 월 4,900원 구독자 10명 정도면 충당합니다. 결제는 매주 쓰는 사용자가 생긴 뒤 붙이고, 지금은 원가 기록과 사용 한도까지 만들어 두었습니다.
- 사용자의 재고·식습관 데이터 판매와 배너 광고는 하지 않습니다.

■ 결과
- 약 108시간, 커밋 749개, 병합 254개
- 백엔드 테스트 1,666개(SQLite·PostgreSQL 통과), 프론트 검사 스크립트 11개, E2E(Playwright) 81개, 화면 시안 16묶음 승인 후 구현
- 사진으로 재고 넣기, 임박 경고, AI 레시피, 링크·사진 가져오기(여러 요리는 최대 5개까지 골라 가져오기), 영상 검색(제목·설명), 양념 비율 계산, 오프라인 장보기, 쇼핑몰에서 한꺼번에 찾기, 식단 짜기(AI 초안·식단으로 장보기), 영양 계산(하루 칼로리 목표·레시피 영양·식단 하루 합계), 먹은 기록 달력, 요리 일기(레시피로·직접 쓰기)·집밥 리포트, 레시피 상세 재고 남은 양·다 썼어요 표시가 지금 동작합니다.
- 체험: 서비스 링크를 누르면 로그인 없이 체험 계정으로 바로 열립니다(로그인 화면은 https://galmuri-kitchen.onrender.com).
- 기술: React·TypeScript·Vite(PWA), Flask·PostgreSQL, Render, Cloudflare R2, YouTube Data API, 식품안전나라 레시피 API, 식품영양성분 DB(공공데이터포털)
```

## 4. 사용 AI툴 및 기술 스택

보이는 칩 중에서 **Claude**, **React** 두 개만 고릅니다.
Next.js·Vercel·Supabase·ChatGPT·Cursor 등은 쓰지 않았으니 고르지 않습니다.

직접 입력 칸이 있으면 아래를 넣습니다.

```text
Claude Code, TypeScript, Vite, PWA(Service Worker·IndexedDB), Flask, PostgreSQL, SQLAlchemy/Alembic, Docker, Render, Cloudflare R2, YouTube Data API, 식품안전나라 레시피 API, 식품영양성분 DB(공공데이터포털)
```

직접 입력 칸이 없으면 3번 본문의 `만드는 과정의 AI — Claude Code` 제목과 마지막 `기술:` 줄로 대신합니다. Claude Code는 필수 기재 대상인 주요 AI 도구라 본문에서 빼지 않습니다.
