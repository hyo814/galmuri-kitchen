# 제출 양식 답안

원티드 AI Championship 2026 제출 양식에 그대로 붙여 넣을 답안입니다.
코드 블록 안의 글이 붙여 넣을 내용입니다. 답안은 심사위원이 읽는 글이라 합니다체로 맞췄습니다.
수치는 4단계 병합 커밋(`c503851`, 2026-09-14 15:49) 기준입니다.

## 1. 제목 (30자 이내)

추천:

```text

```

다른 안:

```text
갈무리부엌: 재고로 요리하고, 모자란 것만 장보기
```

```text
갈무리부엌 — 냉장고 재고·레시피·장보기를 한 흐름으로
```

## 2. 해결하고자 한 문제 (한 줄, 60자 이내)

추천:

```text
사둔 재료를 잊어 상하게 두고, 집에 있는 재료를 모른 채 또 사는 문제
```

다른 안:

```text
재고 기록은 번거로워 멈추고, 레시피와 장보기는 내 냉장고를 모르는 문제
```

```text
남은 재료로 뭘 만들지 몰라 새로 사고, 사둔 재료는 버려지는 문제
```

## 3. AI 활용 방식 및 결과

### 본문 (권장)

```text
■ 서비스 안의 AI — Claude API(Anthropic)
- 사진 인식: 영수증·냉장고 사진·주문 캡처·손메모를 Claude(claude-sonnet-5)가 읽어 재료·수량·보관 위치·금액·구입일을 채웁니다. 사용자는 확인 화면에서 틀린 곳만 고쳐 넣습니다.
- AI 레시피: 곧 먹어야 할 재료를 표시한 재고를 넘겨, 그 재료를 먼저 쓰는 레시피 3개를 받습니다.
- 레시피 가져오기: 유튜브 설명란·블로그 글·붙여 넣은 글을 레시피 초안으로 정리합니다.
- 모든 호출은 구조화 출력(messages.parse + Pydantic 스키마)으로 형식을 강제하고, 형식이 틀리면 결과를 쓰지 않습니다.

■ 안전장치
- 사용자별 하루 한도(사진 10번·레시피 10번)와 60초 연속 제한
- 체험 계정 전체 24시간 300번 예산, 넘으면 예시 결과
- 서버가 결과를 다시 정리(개수·길이·수량·금액 범위)
- 메모 사진·가져온 글 속 문장은 지시가 아닌 자료로만 보는 프롬프트 규칙
- 링크 가져오기 SSRF 방어: 공인 IP만 연결, 리다이렉트마다 재검사, 전체 8초 제한

■ 만드는 과정의 AI — Claude Code
- 설계 문서 → 화면 시안 → 태스크별 계획 → 기능마다 git worktree에서 구현했습니다.
- 리드 에이전트가 계획을 쓰고, 태스크마다 구현 에이전트, 병렬 검토 에이전트(코드·보안·UX·접근성·테스트 설계), 검증 에이전트, 단계 끝 최종 검토와 화면 흐름 점검이 붙었습니다.
- 사람은 기능 범위와 기준을 정하고 시안을 승인했습니다.
- 검토에서 잡은 예
  ① 응답을 조금씩 보내는 서버가 시간 제한을 넘김 → 감시 타이머로 연결 종료
  ② 세션 만료 시 오프라인 체크가 사라짐 → 대기열 보존
  ③ 채널 추가 반복으로 YouTube API 한도 소진 → 사용자별·전체 예산

■ 결과
- 약 29시간, 커밋 289개, 기능 브랜치 병합 101개
- 백엔드 테스트 802개(SQLite·PostgreSQL 통과), 시안 54장 승인 후 구현
- 사진으로 재고 넣기, 임박 경고, AI 레시피, 링크 가져오기, 양념 비율 계산, 오프라인 장보기가 지금 동작합니다.
- 체험: 서비스 링크 → "로그인 없이 체험하기"
- 기술: React·TypeScript·Vite(PWA), Flask·PostgreSQL, Render, Cloudflare R2, YouTube Data API, 식품안전나라 레시피 API
```

### 짧은 버전 (글자 수 제한이 있을 때)

```text
■ 서비스 안의 AI — Claude API(Anthropic, claude-sonnet-5)
- 영수증·냉장고 사진·주문 캡처·손메모를 읽어 재료·수량·금액·구입일을 채우고, 확인 화면에서 고친 뒤 넣습니다.

- 기능마다 git worktree에서 구현 에이전트가 만들고, 코드·보안·UX·접근성·테스트 검토 에이전트가 병렬로 본 뒤 검증 에이전트가 테스트로 확인했습니다. 사람은 기능 범위를 정하고 시안을 승인했습니다.

■ 결과

```

## 4. 사용 AI툴 및 기술 스택

보이는 칩 중에서 **Claude**, **React** 두 개만 고릅니다.
Next.js·Vercel·Supabase·ChatGPT·Cursor 등은 쓰지 않았으니 고르지 않습니다.

직접 입력 칸이 있으면 아래를 넣습니다.

```text
Claude Code, TypeScript, Vite, PWA(Service Worker·IndexedDB), Flask, PostgreSQL, SQLAlchemy/Alembic, Docker, Render, Cloudflare R2, YouTube Data API, 식품안전나라 레시피 API
```

직접 입력 칸이 없으면 3번 본문의 `만드는 과정의 AI — Claude Code` 제목과 마지막 `기술:` 줄로 대신합니다. Claude Code는 필수 기재 대상인 주요 AI 도구라 본문에서 빼지 않습니다.

## 5. 서비스 링크

```text
https://galmuri-kitchen.onrender.com
```

심사 기간에 링크가 열리지 않으면 제외되므로 아래를 지킵니다.

| 완료 | 할 일 | 메모 |
|---|---|---|
| [x] | 웹 서비스를 유료 상시 인스턴스로 바꾸기 | `render.yaml`에서 유료(0.5c-512mb)로 만들었습니다. 무료 플랜은 15분 동안 요청이 없으면 잠들어 첫 접속이 30초가량 걸립니다. 늦어도 9/20 제출 전부터 심사·투표가 끝날 때까지 유지합니다. |
| [x] | PostgreSQL 만료일 확인 | 유료(0.1c-256mb)라 만료되지 않습니다. |
| [ ] | Render Health Check Path 설정 | 앱에 전용 헬스 체크 주소가 없어 `/manifest.webmanifest`(200)를 씁니다. `/api/me`는 로그인 전 401이라 쓰지 않습니다. |
| [ ] | 환경 변수 확인 | `ANTHROPIC_API_KEY`, `DEMO_LOGIN=1`, R2 네 값. 키가 없으면 사진 인식·AI 레시피 버튼이 숨겨집니다. |
| [ ] | Claude API 월 사용 한도와 잔액 확인 | 크레딧이 떨어지면 AI 기능이 오류로 끝납니다. |
| [ ] | 체험 계정 지우기 Cron Job 동작 확인 | `flask --app app purge-demo-users`, 매시 |
| [ ] | 깨끗한 브라우저에서 체험하기 확인 | 시크릿 창(PC)과 휴대폰에서 링크 → `로그인 없이 체험하기` → 재고 화면이 뜨는지. 로그인 기록이 없는 상태로 봅니다. |
| [ ] | 제출 직전과 심사 기간 중 한 번씩 다시 열기 | 사진 인식 1번, AI 레시피 1번까지 확인 |
| [ ] | (선택) 사용자 도메인 | 붙이면 카카오·네이버·구글 Redirect URI도 새 도메인으로 등록합니다. 제출한 링크는 심사 중 바꾸지 않습니다. |

체험 계정은 같은 IP에서 1시간 30개·24시간 100개입니다(`DEMO_IP_HOURLY_LIMIT`·`DEMO_IP_DAILY_LIMIT`). 체험 계정 전체 AI 호출은 24시간 50번(`DEMO_AI_GLOBAL_DAILY`)이고, 넘으면 체험 계정만 예시 결과로 바뀝니다.
