# 갈무리부엌 서비스 소개서

> 사둔 재료, 남김없이 챙겨요

냉장고 재고를 기록하면 상하기 전에 알려 주고, 남은 재료로 레시피를 찾아 주고, 식단과 장보기, 먹은 기록까지 이어 주는 모바일 웹 서비스입니다.

- 체험: https://galmuri-kitchen.onrender.com/?demo=1 — 누르면 로그인 없이 체험 계정으로 바로 열립니다. 로그인 화면은 https://galmuri-kitchen.onrender.com (**로그인 없이 체험하기** 버튼도 있습니다)
- 저장소: [README](../../README.md) · 제품 페이지 [`docs/site/product.html`](../site/product.html) · 케이스 스터디 [`docs/site/portfolio.html`](../site/portfolio.html)
- 기준: 5단계 화면 병합본(`stage5-ui` `662b928`, 2026-09-16 03:16).

## 1. 문제

집에서 요리하는 사람은 세 곳에서 재료를 잃습니다.

| 순간 | 일어나는 일 |
|---|---|
| 냉장고 앞 | 날짜를 적지 않은 두부·요거트가 안쪽에서 잊혀 상합니다. |
| 저녁 메뉴 고민 | 있는 재료로 뭘 만들지 떠오르지 않아 새로 삽니다. |
| 마트 | 집에 대파가 있었는지 기억나지 않아 겹쳐 사고, 참기름은 빠뜨립니다. |

재고 앱은 입력이 번거로워 며칠 뒤 멈추고, 레시피 앱은 내 냉장고를 모르고, 장보기 메모는 재고와 따로 놉니다.

## 2. 대상

- **가족 살림을 맡은 사람**: 냉장고가 여러 대이고 한 번에 많이 삽니다. 영수증 한 장으로 재고를 넣고, 마트에서 목록을 체크합니다.
- **혼자 사는 사람**: 조금씩 사서 오래 둡니다. 반 모 남은 두부를 잊지 않게 알림을 받고, 남은 재료로 한 끼를 찾습니다.

실사용 기기는 갤럭시 S22 Ultra(뷰포트 약 384px)를 기준으로 맞췄습니다.

## 3. 해결

재고 → 레시피·식단 → 장보기 → 재고로 도는 한 흐름을 만들었습니다.

1. 영수증·냉장고 사진을 여러 장 한 번에 찍으면 AI가 재료·수량·금액·구입일을 채웁니다. 확인하고 한 번에 넣습니다.
2. 곧 먹어야 할 재료가 위로 올라오고, 떨어진 필수품이 첫 화면에 뜹니다.
3. 재고와 겹치는 레시피를 일치율 순으로 보고, 임박 재료를 먼저 쓰는 AI 레시피를 받습니다. 한 주 식단을 짜거나 AI 초안을 받고, 하루 칼로리 목표와 식단 합계를 봅니다.
4. 레시피나 식단에서 모자란 재료를 장보기 목록에 담고, 마트에서 인터넷 없이 체크합니다.
5. 체크한 항목을 재고에 넣으면 1번으로 돌아갑니다. 먹은 끼니는 달력에 남깁니다.

## 4. 핵심 기능 8개

| 기능 | 내용 |
|---|---|
| **사진으로 재고 넣기** | 냉장고 사진·영수증·온라인 주문 캡처를 최대 5장까지 한 번에 Claude가 읽습니다(한도 1회). 보관 위치 종류까지 추정하고, 확인 화면에서 구입일 칩·`기억 안 나요`로 고친 뒤 넣습니다. |
| **임박·경고 배지** | `D-2`, `구입 16일째`, `섭취 주의`. 식약처 참고값 기반 품목별 규칙, 냉장 7일·냉동 60일 기준, 떨어진 필수품 배너. |
| **재고 기반 레시피** | 식약처 공공 레시피(인증키 연결 후 약 1,100건)와 내 레시피를 일치율 순으로 추천합니다. AI 레시피 3개, 유튜브·블로그 링크와 요리책 사진(5장) 정리(한 페이지에 요리가 여럿이면 최대 5개까지 골라 가져오기), 기본 요리 채널 14곳 영상(제목·설명 검색)도 있습니다. 레시피 상세는 재료마다 재고 남은 양(`있어요 300g`)을 보여 줍니다. |
| **양념 비율 계산기** | 고기 900g이면 양념을 얼마나 넣을지 계산합니다. `3½큰술`처럼 뜰 수 있는 분수와 `밥숟가락 약 4개`를 함께 보여 줍니다. |
| **매장 장보기** | 날짜별 목록, 제자리 체크, 쇼핑몰 6곳(쿠팡·네이버 쇼핑·컬리·이마트몰·롯데마트·G마켓, 모두 낮은 가격순) 검색 링크(한 번에 쇼핑몰을 고르면 살 것마다 찾기 링크를 차례로 여는 `한꺼번에 찾기` 포함), 손메모·전단지 사진에서 살 것 뽑기, 오프라인 체크, 체크한 항목 재고에 넣기. |
| **식단 짜기** | 주·월 보기, 내 레시피(재고 일치)·영상·직접 쓰기로 칸 채우기, 이번 주 복사, 목표 kcal을 받아 칸마다 후보 2개를 주는 AI 식단 초안, 식단에서 모자란 재료만 장보기로. |
| **영양 계산** | 내 몸 정보(성별·출생연도·키·몸무게·활동량·목표)로 하루 칼로리 목표를 정하고, 레시피 1인분 영양(탄수화물·단백질·지방·당류·나트륨)과 식단 하루 합계를 봅니다. 재료는 식품영양성분 DB에서 찾고, 못 찾은 재료만 AI가 추정해 `추정`으로 표시합니다. |
| **먹은 기록** | 끼니마다 식단에서·내 레시피·음식 찾기·직접 쓰기로 먹은 것을 남기고, 양·집밥/외식·만족도·메모·사진(4장)을 붙입니다. 식단 칸에서 `먹었어요`로 바로 기록하고, 한 달 달력으로 봅니다. |

요리 일기와 집밥 리포트는 화면까지 동작합니다(요리했어요로 쓴 재료 빼기·10초 안 되돌리기, 일기 목록·상세·사진, 아낀 돈 계산, 월간 리포트, 일기 내보내기와 체험 계정 예시 일기).

## 5. AI 활용

### 서비스 안

- **사진 인식**(냉장고·영수증·주문 캡처 최대 5장, 손메모): Claude 구조화 출력으로 JSON 스키마를 강제하고, 서버가 개수·길이·금액 범위를 한 번 더 정리합니다.
- **AI 레시피**: 재고와 임박 표시를 넘겨 레시피 3개를 받습니다. 사진은 생성하지 않고 이름이 비슷한 공공 레시피 사진을 출처를 밝혀 씁니다.
- **레시피 가져오기**: 유튜브 설명란·블로그 본문(글에 레시피가 없으면 본문 사진도)·붙여 넣은 글·요리책 사진을 레시피 초안으로 바꿉니다.
- **AI 식단 초안**: 끼니·목표 kcal·메모를 받아 빈 칸마다 후보 2개와 1인분 kcal 추정을 만듭니다. 새 요리는 넣을 때 한 번만 내 레시피로 저장합니다.
- **영양 추정**: 식품영양성분 DB에서 찾지 못한 재료의 100g당 영양과 `두부 1모`처럼 한 단위가 몇 g인지를 한 번에 추정합니다. 재료 이름 기준 추정값은 모든 사용자가 함께 써서 같은 재료를 다시 묻지 않습니다.
- **사 먹으면 얼마 추정**: 레시피 이름과 재료 이름(최대 15개)으로 1인분을 사 먹으면 보통 얼마인지 추정합니다. 레시피에 값이 없을 때만 한 번 부르고 결과를 레시피에 저장하며, 1,000~100,000원 밖이면 버립니다. 요리 일기의 아낀 돈 계산에 씁니다.
- **비용 관리**: 사용자별 하루 한도(사진 인식 20번, AI 레시피·가져오기·식단 초안·사 먹으면 얼마 추정 합쳐 20번, 영양 추정은 따로 20번), 60초 연속 제한, 체험 계정은 사진 인식·AI 레시피 각각 하루 5번(영양 추정 2번)과 체험 계정 전체 24시간 80번 예산(배포 설정, 코드 기본 300)·영양 추정 하루 30번, 호출별 모델·토큰 기록.

### 만드는 과정

Claude Code로 설계부터 배포 준비까지 만들었습니다. 역할을 나눈 에이전트(구현·코드 검토·보안 검토·UX·접근성 검토·테스트 설계 검토·검증)가 태스크마다 붙고, 화면은 사용자가 시안을 승인한 뒤 구현했습니다. 자세한 과정은 [03-AI-개발-과정](03-AI-개발-과정.md)에 있습니다.

## 6. 수익 구조와 원가

갈무리부엌에서 쓸수록 드는 비용은 대부분 AI 호출입니다. 호출마다 모델과 입력·출력 토큰을 `ai_calls`에 기록하고 있고, 추정 원가는 영수증 1장 인식 약 13원, AI 레시피 3개 약 30원, 한 주 식단 초안 약 70원입니다(추정값).

- **무료로 두는 것**: 재고·임박 경고·공공 레시피 추천·오프라인 장보기처럼 AI가 필요 없는 기능.
- **유료 구독(검토, 월 2,900~4,900원)**: 비용이 드는 AI 사용 횟수로만 무료와 나누고, 원가가 없는 레시피 개수에는 제한을 두지 않습니다. 구독할 이유는 집밥 리포트의 `아낀 돈`(사 먹으면 얼마 × 인분 − 쓴 재료비, 추정값)으로 보여 드립니다. 더보기 집밥 리포트에서 볼 수 있습니다.
- **제휴 링크**: 장보기의 쇼핑몰 링크는 쿠팡 파트너스 제휴 링크로 바꿀 수 있게 만들어 두었습니다(키를 넣으면 켜짐). 제휴 링크에는 `광고` 표시를 붙이고, 쇼핑몰 순서는 수수료와 상관없습니다(마지막에 쓴 쇼핑몰만 앞으로). 체험 계정은 서버가 늘 일반 쇼핑몰 링크로 보내므로 심사 중에는 제휴 링크와 `광고` 표시가 보이지 않습니다.
- **고정비**: 서버와 DB는 월 약 2만 원(추정)이라 월 4,900원 구독자 10명 정도면 충당합니다.
- **순서**: 결제는 매주 쓰는 사용자가 생긴 뒤 붙이고, 지금은 원가 기록과 사용 한도까지 만들어 두었습니다.
- **하지 않는 것**: 사용자의 재고·식습관 데이터 판매와 배너 광고.

## 7. 차별점

| 차별점 | 설명 |
|---|---|
| **오프라인 매장 장보기** | 마트 지하에서도 목록이 열리고 체크·추가·메모가 됩니다. 변경은 기기에 쌓였다가 연결되면 한 번만 반영됩니다(`client_id`). 다른 기기와 메모가 겹치면 덮지 않고 따로 보관합니다. |
| **생활용품 분리** | 수세미·휴지·세제는 장보기 목록에 담되 재고에는 넣지 않습니다. 이름으로 짐작하고 줄마다 바꿀 수 있습니다. |
| **식약처 기준 경고** | 감으로 정한 날짜가 아니라 「식품유형별 소비기한 설정 보고서」 참고값(두부 23일, 햄 57일 등)을 구입일 기준 80%로 환산했습니다. 우유처럼 참고값이 없는 품목은 규칙을 두지 않고 포장 날짜 입력을 안내합니다. |
| **숟가락 단위 계산** | ml·g 대신 계량스푼 분수(¼·⅓·½·⅔·¾)로 반올림하고, 큰술이 작으면 작은술로 바꿉니다. 집 밥숟가락 환산도 함께 보여 줍니다. |
| **체험 계정** | 소셜 로그인 없이 예시 재고가 든 계정으로 바로 둘러봅니다. 24시간 뒤 사진까지 지웁니다. |
