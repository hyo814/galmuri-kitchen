# 갈무리부엌 서비스 소개서

> 사둔 재료, 남김없이 챙겨요

냉장고 재고를 기록하면 상하기 전에 알려 주고, 남은 재료로 레시피를 찾아 주고, 장보기까지 이어 주는 모바일 웹 서비스입니다.

- 체험: https://galmuri-kitchen.onrender.com → **로그인 없이 체험하기**
- 저장소: [README](../../README.md)

## 1. 문제

집에서 요리하는 사람은 세 곳에서 재료를 잃습니다.

| 순간 | 일어나는 일 |
|---|---|
| 냉장고 앞 | 날짜를 적지 않은 두부·요거트가 안쪽에서 잊혀 상합니다. |
| 저녁 메뉴 고민 | 있는 재료로 뭘 만들지 떠오르지 않아 새로 삽니다. |
| 마트 | 집에 대파가 있었는지 기억나지 않아 겹쳐 사고, 참기름은 빠뜨립니다. |

재고 앱은 입력이 번거로워 며칠 뒤 멈추고, 레시피 앱은 내 냉장고를 모르고, 장보기 메모는 재고와 따로 놉니다.

## 2. 대상

- **가족 살림을 맡은 사람**: 냉장고가 여러 대이고 한 번에 많이 삽니다. 영수증 한 장으로 재고를 넣고, 마트에서 목록을 체크합니다.
- **혼자 사는 사람**: 조금씩 사서 오래 둡니다. 반 모 남은 두부를 잊지 않게 알림을 받고, 남은 재료로 한 끼를 찾습니다.

실사용 기기는 갤럭시 S22 Ultra(뷰포트 약 384px)를 기준으로 맞췄습니다.

## 3. 해결

재고 → 레시피 → 장보기 → 재고로 도는 한 흐름을 만들었습니다.

1. 영수증을 찍으면 AI가 재료·수량·금액·구입일을 채웁니다. 확인하고 한 번에 넣습니다.
2. 곧 먹어야 할 재료가 위로 올라오고, 떨어진 필수품이 첫 화면에 뜹니다.
3. 재고와 겹치는 레시피를 일치율 순으로 보고, 임박 재료를 먼저 쓰는 AI 레시피를 받습니다.
4. 없는 재료를 장보기 목록에 담고, 마트에서 인터넷 없이 체크합니다.
5. 체크한 항목을 재고에 넣으면 1번으로 돌아갑니다.

## 4. 핵심 기능 6개

| 기능 | 내용 |
|---|---|
| **사진으로 재고 넣기** | 냉장고 사진·영수증·온라인 주문 캡처를 Claude가 읽습니다. 보관 위치 종류까지 추정하고, 확인 화면에서 고친 뒤 넣습니다. |
| **임박·경고 배지** | `D-2`, `구입 16일째`, `섭취 주의`. 식약처 참고값 기반 품목별 규칙, 냉장 7일·냉동 60일 기준, 떨어진 필수품 배너. |
| **재고 기반 레시피** | 식약처 공공 레시피(인증키 연결 후 약 1,100건)와 내 레시피를 일치율 순으로 추천합니다. AI 레시피 3개, 유튜브·블로그·사진 정리, 요리 채널 영상도 있습니다. |
| **양념 비율 계산기** | 고기 900g이면 양념을 얼마나 넣을지 계산합니다. `3½큰술`처럼 뜰 수 있는 분수와 `밥숟가락 약 4개`를 함께 보여 줍니다. |
| **매장 장보기** | 날짜별 목록, 제자리 체크, 쇼핑몰 7곳 검색 링크, 손메모·살 것 사진 인식, 오프라인 체크, 체크한 항목 재고에 넣기. |
| **식단 짜기** | 한 주·한 달 식단 달력, 재고와 겹치는 재료·영상·직접 쓰기로 칸 채우기, 목표 kcal에 맞춘 AI 식단 초안, 식단에서 모자란 재료만 장보기로. |

## 5. AI 활용

### 서비스 안

- **사진 인식**(냉장고·영수증·주문 캡처·손메모): Claude 구조화 출력으로 JSON 스키마를 강제하고, 서버가 개수·길이·금액 범위를 한 번 더 정리합니다.
- **AI 레시피**: 재고와 임박 표시를 넘겨 레시피 3개를 받습니다. 사진은 생성하지 않고 이름이 비슷한 공공 레시피 사진을 출처를 밝혀 씁니다.
- **링크 정리**: 유튜브 설명란·블로그 본문·붙여 넣은 글을 레시피 초안으로 바꿉니다.
- **비용 관리**: 사용자별 하루 한도(사진 10번·레시피 10번), 60초 연속 제한, 체험 계정 전체 24시간 300번 예산, 호출별 토큰 기록.

### 만드는 과정

Claude Code로 설계부터 배포 준비까지 만들었습니다. 역할을 나눈 에이전트(구현·코드 검토·보안 검토·UX·접근성 검토·테스트 설계 검토·검증)가 태스크마다 붙고, 화면은 사용자가 시안을 승인한 뒤 구현했습니다. 자세한 과정은 [03-AI-개발-과정](03-AI-개발-과정.md)에 있습니다.

## 6. 차별점

| 차별점 | 설명 |
|---|---|
| **오프라인 매장 장보기** | 마트 지하에서도 목록이 열리고 체크·추가·메모가 됩니다. 변경은 기기에 쌓였다가 연결되면 한 번만 반영됩니다(`client_id`). 다른 기기와 메모가 겹치면 덮지 않고 따로 보관합니다. |
| **생활용품 분리** | 수세미·휴지·세제는 장보기 목록에 담되 재고에는 넣지 않습니다. 이름으로 짐작하고 줄마다 바꿀 수 있습니다. |
| **식약처 기준 경고** | 감으로 정한 날짜가 아니라 「식품유형별 소비기한 설정 보고서」 참고값(두부 23일, 햄 57일 등)을 구입일 기준 80%로 환산했습니다. 우유처럼 참고값이 없는 품목은 규칙을 두지 않고 포장 날짜 입력을 안내합니다. |
| **숟가락 단위 계산** | ml·g 대신 계량스푼 분수(¼·⅓·½·⅔·¾)로 반올림하고, 큰술이 작으면 작은술로 바꿉니다. 집 밥숟가락 환산도 함께 보여 줍니다. |
| **체험 계정** | 소셜 로그인 없이 예시 재고가 든 계정으로 바로 둘러봅니다. 24시간 뒤 사진까지 지웁니다. |

## 7. 지표와 검증

| 항목 | 수치 |

## 8. 향후 계획

1. **배포 후**: Render 배포, 쇼핑몰 정렬 링크 폰 확인, 식약처 레시피 전체 동기화, 체험 계정 IP 한도 확인.
2. **영양 계산**: 기초대사량·내 몸 정보, 식단 칸의 칼로리·당류 합계.
3. **먹은 기록**: 끼니별 음식·kcal·사진·메모를 달력으로 봅니다.
4. **요리 기록**: `요리했어요`로 쓴 재료를 재고에서 빼고 사진·별점을 남깁니다(요리 일기).
5. **집밥 리포트**: 이번 달 버린 재료 수와 아낀 돈(사 먹으면 얼마 − 집밥 재료비). 영수증 인식이 이미 품목별 금액을 저장하고 있습니다.

식단 짜기(1주·1달 달력, AI 초안, 식단→장보기)는 이미 구현했습니다. 자세한 내용은 §4를 참고하세요.
